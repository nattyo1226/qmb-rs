# qmb-rs 要件

更新日: 2026-10-26

## 1. 文書の目的と責任分離

本文書は、qmb-rs の目的、責任分離、機能要件、数学的・数値的規約、および検証方針を定め、開発計画の基準とする。

2026-10-26 に LocalStructure の廃止方針を採用した。primitive の意味・規則は S・O の型と各能力の実装で定め、追加の定義ラベルは設けない。次元は primitive 型全体の span、恒等元は演算子 primitive O の値として提供する。L による関連付け・一致判定は廃止し、[局所構造の設計第7節](design/local-structure.md#7-localstructure-廃止の採用方針2026-10-26)で置き換える。製品コード・テスト・利用例を移行済みである。

同日に、Chain は Site ごとの Index 列と境界条件を直接保持し、Geometry 構造体と HilbertSpace の保持を廃止する方針を採用した。以下の幾何・配置の要件は移行先を表し、製品コード・テスト・利用例の移行は未着手である。詳細は[Chain の設計](design/geometry.md)と[実装計画第9節](implementation-plan.md#9-chain-の-index-列保持への移行実装未着手)に記録する。

初期版の提供範囲と完成条件は、[初期版の設計](design/initial-release.md)に定め、9 節にその概要と制限をまとめる。本書には後続機能の数学的契約も含め、機能一覧全体を初期版の必須実装にはしない。公開 API、Rust の具体的な型や内部実装は、本文で採用済みの方針に従って各段階で具体化する。

初期版では、一つの系を同じ primitive 型 S・O で表す一種類の局所代数から構成する。空間・状態・演算子式に含まれる全基本因子は同じ局所構造を持ち、異種局所構造の混在・合成は後続へ延期する。独自代数を別の系として単独利用する拡張性は維持する。同じ局所構造の複数因子、入れ子 Tensor、および一つの Site への複数自由度の配置は初期版に含める。

qmb-rs は、量子系の Hilbert 空間、状態、および演算子を代数的に構築・合成・評価し、必要に応じて数値計算 backend へ export する汎用ライブラリとする。

演算子基底の構成・列挙、行列を生成しない代数計算、および再利用可能な係数データの生成を提供する。第一目標はシンボリックな構造を保持しつつ必要な部分を密表現へ export できることであり、密・疎表現への四つの変換経路を提供する。

以下の対象ごとに、定義、操作、制約、および検証条件をまとめる。局所構造から埋め込み・評価までと、基底・係数データの構築は代数 core が担当し、幾何・モデル構築と数値 backend への export はその上に接続する。

代数 core は `qmb-core` に集約する。具体的代数は `qmb-spin-half` などの専用 crate、幾何と Site への配置は `qmb-geometry`、外部数値コンテナへの変換は `qmb-export`、Heisenberg・Neel の構築 utility は `qmb-spin-half`、再公開・利用例は `qmb` が担当する。共通の型・式木・評価・基底処理を core の module として分離し、具体的代数には独自の式木・evaluator を要求しない。責任と依存関係は[実装計画](implementation-plan.md)に定める。

| 対象 | 担当すること | 記述先 |
| --- | --- | --- |
| 局所構造 | 有限次元の表現、primitive、局所積・作用・随伴・内積・trace | 2 節 |
| 自由度・Hilbert 空間 | 因子の同一性、順序、合成規則、内部因子と grouping の対応 | 3 節 |
| 状態式・演算子式 | core が管理する共通の構文、不変な部分構造の共有 | 4 節 |
| 埋め込み・評価 | 全作用空間の確定、整合性検証、grading、必要な部分の評価 | 5 節 |
| 基底・export | 座標取得、係数データ、外部ライブラリの密・疎表現への変換 | 6 節 |
| 幾何・モデル構築 | site と関係、自由度の配置、Hamiltonian などの構築 | 7 節 |

モデル構築は代数 core を利用するが、core は幾何構造を必須の前提としない。自由度と式を直接構築する利用も可能にする。代数オブジェクトの構築・合成・評価は、完全な密行列や疎行列の生成に依存してはならない。

各章の検証条件は、その機能を実装する際に適用する。複数の責任を横断する代表ユースケースと受入条件は、8 節にまとめる。

## 2. 局所構造

### 2.1. 定義と拡張の責任

局所構造は、局所 Hilbert 空間と、その上に作用する局所代数・表現を定める。抽象的な代数関係だけでは作用空間や表現が一意に決まらない場合があるため、具体的な作用を指定する情報も含める。

局所構造、自由度の同一性、基底を分ける。局所代数を固定しても、自由度の数・Index・配置・順序や基底は決まらない。局所構造が既定の基底を提供してもよいが、空間と基底は同一視しない。

局所構造は空間の情報を保持し、状態・演算子 primitive が持つ数学的能力を関連付け、その整合性を要求する。状態 primitive は内積と演算子の作用を受ける Act、演算子 primitive は Product・随伴・trace を提供し、core の共通の式木が線型結合などへ拡張する。詳細は [局所構造の設計](design/local-structure.md)と[局所 primitive・式木の数学的能力](design/primitive-expression.md)に定める。

Rust API は演算子式に O・C、状態式に S・O・C を指定する。恒等元は O の Identity、次元は S・O の SpanDimension とし、LocalStructure は公開しない。各演算能力と入出力の対応は必要なメソッドで要求し、式の単なる保持・構築に演算の数値制約を波及させない。

局所構造は、同じ定義・定義パラメータを持つ場合に一致とする。別々に構築・復元した場合も一致し、選択基底・表示名・メモリ上の object identity は一致条件に含めない。次元や trait の種類の一致だけでは一致とみなさず、数学的同型の判定や primitive の自動対応付けは導入しない。詳細は[局所構造の一致条件](design/local-structure.md#4-局所構造の一致条件)に定める。数値精度の互換性は 4.1 節の規約に従って別途検証する。

局所 Hilbert 空間が持つ代数構造は、適切な抽象化の下で差し替え可能とする。spin-1/2 固有の規則を、状態、演算子、または数値変換の共通処理へ直接埋め込んではならない。

局所代数の抽象化は、少なくとも以下の情報または操作を提供できるものとする。

- 局所 Hilbert 空間の次元
- 順序付けられた局所基底
- 順序付けられた局所演算子基底とその列挙・座標取得に必要な情報
- 局所状態および局所演算子の識別
- 恒等演算子
- 局所演算子の積
- 局所演算子の adjoint
- 局所演算子の局所状態への作用
- 局所状態の内積
- 局所演算子の trace
- 上記の局所演算に必要な代数規則
- 密および疎の局所数値表現を得るために必要な情報
- Grading に対応する場合の状態・演算子の parity と局所 parity 演算子

spin-1/2 を標準例としてこの抽象化を検証する。spin-S、qudit、boson、または fermion を追加する際に、物理空間、複合 Hilbert 空間、代数式、および数値変換の共通機構を全面的に変更する必要がないことを目標とする。

新しい局所代数の追加は、既存の局所代数を列挙した closed な分岐を共通処理へ追加する方法ではなく、抽象化の新しい実装を提供する方法で行えるものとする。局所複合代数は共通の合成機構へ委譲して同じ操作を提供する。

異なる基本代数の合成は後続の機能候補とし、初期版には異種構造の保持・型消去・評価機構を要求しない。将来この合成を導入する場合は、scalar・grading・交換規則などの互換性を要求する。合成する空間の数学的条件は 3 節、因子間の交換・grading の規約は 5.5 節に定める。

基本局所代数は自身の局所規則を担当し、局所空間だけでは完結しない交換・grading は共通の複合代数機構が担当する。

### 2.2. 局所複合代数

局所代数と局所自由度を組み合わせ、局所的だが複合的な代数を構築できるようにする。局所複合代数は通常の局所代数と同じ操作を提供し、構成する内部自由度とその順序を保持する。構築時に指定した内部自由度を、site への配置前後にも保持・利用できるようにする。大域空間の構成と配置側の対応は、3.3 節に定める。

局所複合代数をさらに別の複合代数の構成要素にできるようにする。初期版の全基本因子は同じ局所構造とする。spinful fermion への graded な拡張、および独立した spin・orbital などの異種局所構造の合成は後続の機能候補である。

局所複合代数の空間は、子に複合空間を含められる Hilbert 空間の再帰構造で表す。数学的能力は、子の局所規則と共通の合成・評価機構から処理する。Grouping は空間の木の括り方で表し、そのための独立した Group 型は追加しない。詳細は [Hilbert 空間の再帰構造](design/hilbert-space.md)に定める。

| 担当 | 責任 |
| --- | --- |
| 基本となる局所代数 | 自身の局所積、作用、随伴、内積、trace、基底、grading 情報を提供する |
| 複合代数の合成機構 | 因子への埋め込み、因子間の交換・grading、順序管理、各操作の合成、複合基底の構成を行う |
| 局所複合代数 | 内部自由度と順序を保持し、合成機構へ委譲して通常の局所代数と同じ操作を提供する |
| Hilbert 空間の木による grouping | 子空間を括り、基本因子と階層の対応を保持する |
| Site への配置 | Chain が Site 順の Index 列を保持し、空間・grouping・全体の因子順序は利用側が管理する |
| 大域空間と埋め込み | 基本因子の Index・順序・局所構造と、積の種類・構造を保持する |

複合 Hilbert 空間は、局所構造に相当する整合性の責任を持つ。子の構造・因子順序・積の種類から数学的能力を合成し、共通機構が局所契約を保存する合成則を実現する。独立した複合構造型は要求しない。能力一覧と合成・整合性の詳細は、[埋め込み・複合空間の式と数学的能力](design/composite-expression.md)に定める。

### 2.3. Spin-1/2 の規約

`hbar = 1` とし、Pauli 行列との関係を

```math
S^\alpha = \frac{1}{2}\sigma^\alpha
```

と定める。ladder operator は

```math
S^+ = S^x + iS^y, \qquad
S^- = S^x - iS^y
```

とする。

既定の局所基底の順序は

```math
(|\uparrow\rangle, |\downarrow\rangle)
```

とし、それぞれ `Sz` の固有値 `+1/2` および `-1/2` に対応させる。この基底における局所行列表現は次のとおりとする。

```math
S^x = \frac{1}{2}
\begin{pmatrix}0&1\\1&0\end{pmatrix}, \qquad
S^y = \frac{1}{2}
\begin{pmatrix}0&-i\\i&0\end{pmatrix}, \qquad
S^z = \frac{1}{2}
\begin{pmatrix}1&0\\0&-1\end{pmatrix}
```

```math
S^+ =
\begin{pmatrix}0&1\\0&0\end{pmatrix}, \qquad
S^- =
\begin{pmatrix}0&0\\1&0\end{pmatrix}
```

### 2.4. Graded な局所構造と spinful fermion

Fermion に対応するための責任分離を定める。基本局所構造は演算子・状態の parity と局所積・作用の規則を提供する。単一 mode の例では `c,c†` は odd、`I,n` は even であり、`c²=0`、`cc†+c†c=I` を満たす。

Graded な局所構造の状態・演算子 primitive はそれぞれ even または odd の homogeneous なものに限定し、混合 parity の対象は式の和で表す。この制限のもとでも primitive の線型結合が全対象空間を張ることを要求する。局所規則は grading と整合し、zero の parity の選択は計算結果に影響させない。

spinful fermion は、物理 site `i` と mode `(i,σ)` を区別する。spin-1/2 の場合、up・down の二次元占有空間を graded に合成した四次元局所複合代数として扱う。site 単位の操作と構築時の内部 mode の利用、大域空間での基本因子の走査には、3.3 節の共通機構を用いる。

四つの局所状態の表示例は空、up のみ、down のみ、二重占有である。内部順序を up,down、二重占有状態の位相を `|up down>=f_up† f_down†|0>` とすると、`f_up|up down>=|down>`、`f_down|up down>=-|up>` となる。これらの符号は共通の合成規則から得る。

```math
\{f_\sigma,f_\tau\}=0,
\qquad \{f_\sigma,f_\tau^\dagger\}=\delta_{\sigma\tau}I,
\qquad P_i=(-1)^{n_{i,\mathrm{up}}+n_{i,\mathrm{down}}}.
```

上記の表示基底で総 parity は `diag(+1,-1,-1,+1)` となる。

局所構造が複数の odd な primitive を持てるようにし、一つの基本因子に一つの生成消滅演算子しかないという仮定を core に入れない。

### 2.5. 検証条件

- `Sx`, `Sy`, `Sz` が Hermitian である。
- `S+` と `S-` が互いに adjoint である。
- spin 演算子が採用した規約における交換関係を満たす。
- spin-1/2 の実装が局所代数の抽象化を通じて利用され、共通処理が spin-1/2 固有の分岐を必要としないことを確認する。
- core 部分の差し替え可能性を検証するため、公開対象ではない test 用の別の有限次元局所代数を同じ抽象化で実装し、別の系として状態への作用、trace、および数値変換の共通機構を利用できることを確認する。この test 用 algebra を公開 builtin の追加と同一視しない。
- 独自の局所構造・primitive・局所規則・基底を追加しても、builtin の状態式・演算子式を使って評価でき、独自の式木や内部 evaluator の実装が不要であることを確認する。
- 局所複合代数が通常の局所代数と同じ操作を提供し、階層的な評価と基本因子へ展開した評価が一致する。

## 3. 自由度・Hilbert 空間

### 3.1. 自由度の同一性と空間の構成

Index は局所構造から独立した識別子であり、局所構造や次元を持たない。基本自由度は Index と局所構造を持つ `HilbertSpace` の葉（Factor）として表し、独立した `Dof` 型は設けない。同じ局所構造を持っていても、異なる Index を持つ自由度は独立した因子である。Index の一意性は、衝突確率が十分低い生成方式を前提として仮定する。独立した発行、自由度の構築、および局所状態・演算子への付与の契約は、[Index の設計](design/index.md)に定める。Index は基底の座標を指定する数値的な index と区別する。

`qmb-core` は Index 型をジェネリックに扱い、同じ Index であることを照合できることを契約とする。具体的な表現・発行・一意性の確保は提供側の責任とし、標準の具体実装は `qmb-basic` に UUID の具体型と seed 指定を要求しない発行 API を置く。core は UUID・乱数源に依存せず、`no_std + alloc` を維持する。

保存した対象の復元は元の Index を保持し、独立した系の作成は新しい Index に参照を一貫して付け直す。複数ランタイムから対象を持ち寄る場合は、Index で因子を照合し、局所構造と空間の互換性を検証する。詳細は [Index の保存・復元と複数ランタイムの契約](design/index.md#7-保存復元と複数ランタイム)に定める。保存形式と具体的な API は未決とし、保存機能や並列評価を初期版の必須実装には追加しない。

有限次元の局所 Hilbert 空間と、その tensor product を扱う。基本因子の Index、局所構造、および tensor ordering を明示的に保持する。因子順序は Index の順序付き列で指定し、Index の値の大小から決めない。標準例は 2.3 節の spin-1/2 とし、site と局所 Hilbert 空間の対応は 7 節の配置情報として扱う。

Hilbert 空間自体を、基本自由度の Index と局所構造を持つ Factor、および ordinary / graded の種類と順序付きの子 Hilbert 空間を持つ Tensor の再帰構造とする。Tensor の子に Tensor を含められる。基本因子の順序は子を左から順にたどった葉の順序とする。Factor・Tensor は概念上の名前とし、具体的な Rust 型は実装設計に委ねる。詳細は [Hilbert 空間の再帰構造](design/hilbert-space.md)に定める。

空間・状態の tensor product による合成は、独立な因子への分解が指定された対象に適用する。内部ラベルだけから分解を推論せず、初期版では制約付き部分空間を扱わない。

### 3.2. Tensor product と空間の互換性

空間の tensor product は、左 operand の基本因子を左側、右 operand の基本因子を右側に配置する。基本因子の重複と合成条件の互換性を検証する。

複合対象とその内部因子を独立した因子として重複追加してはならない。tensor product の重複検証は基本因子に対して行う。一方、同じ大域空間に埋め込まれた演算子同士の通常の積は許可する。

同じ種類の積に対する結合則は、括り方が異なる空間の互換性判定に用いる。利用者向けの Regrouping 操作、因子順序の変更、および permutation は提供しない。階層的な評価と、積の種類を保持して基本因子へ展開した評価が一致するようにする。

0-site Hilbert 空間は一次元とする。

空の Tensor は種類によらず共通の一次元空間、単因子 Tensor はその因子の空間と同一視する。一次元の空因子空間は通常・graded の両方で積の単位元とし、graded な構成ではその状態 `1` を even とする。複数因子の合成には積の種類を保持し、構築した空間の括り方を一律に変更する必要はない。

Tensor の次元は子空間の次元の積とする。Index を持つ一次元の Factor は空の Tensor と区別し、次元だけを理由に基本因子を取り除かない。保持する木構造と数学的な互換性を分け、構築時の平坦化を要求しない。不変な子空間を共有できるようにする。

総次元が `usize` に収まることを空間構築の条件にしない。整数としての次元取得や数値コンテナの要素数計算では overflow を検出し、暗黙に切り詰めない。行列を作らない作用・内積・trace のために、総次元を整数化することを必須にしない。具体的な型・共有・検証・評価の採用方針は [Step 3 の実装方針](step-3-design.md)に定める。

```math
\dim \mathcal H_{\varnothing}=1, \qquad
\operatorname{Tr}(I_{\varnothing})=1
```

二つの Hilbert 空間は、基本因子の Index・順序・局所構造と、空・単因子 Tensor の同一視および同種の積の結合則を適用した後の tensor product の種類・構造が一致するときに互換とみなす。内部的な object identity や次元だけを互換性の条件とはしない。Grouping の表示のみを変更しても基本因子の同一性と順序は維持する。異なる Index を暗黙に同一視せず、因子順序を変更する permutation はサポートしない。

空間 `K` が `H` の部分系であることも判定できるようにする。`K` の基本因子の Index が `H` に含まれ、対応する局所構造が一致し、基本因子列が相対順序を保存した部分列となり、空・単因子の同一視後の積の種類が整合することを条件とする。木の部分木や連続した因子列であることは要求しない。空間自身と空の Tensor は部分系とする。詳細は [部分系の判定](design/hilbert-space.md#6-部分系の判定)に定める。任意の因子集合を指定した部分系の取得操作は提供しない。

少なくとも以下を検出してエラーとして扱う。

- 重複または不正な基本因子の Index
- 同じ基本因子を含む空間または状態の tensor product。複合対象と内部因子の重複も含む
- 初期版の一つの Hilbert 空間内における、単位元と単因子 Tensor の同一視を適用した後にも残る通常・graded tensor product の混在
- Scalar・grading・交換規則が互換でない合成

### 3.3. 内部因子の展開と grouping

局所空間の tensor product から大域空間を構成するときは、複合空間を子として持つ木構造を保持できる。Chain は Site ごとの Index 列を保持し、利用側が空間の grouping と因子順序を管理する。初期版では内部ラベルを導入しない。利用者は構築時に保持した空間・自由度を演算の対象として指定でき、core は必要な検証・評価時に木の基本因子をたどる。任意の因子集合を指定した部分系の取得操作は要求しない。

Hilbert 空間は、Tensor の直下の子空間を構築順序で列挙する能力と、全葉の Index を因子順序で列挙する能力を提供する。入れ子を保持して子を読む操作と、再帰的に全 Index を読む操作を区別する。Factor の Index は一要素、空の Tensor はゼロ要素とし、Iterator として利用できる遅延列挙で、空間・Index・順序を変更しない。式・基底・行列は展開しない。詳細は [構成要素の列挙](design/hilbert-space.md#7-構成要素の列挙と不変構造の共有)に定める。

同じ局所構造 `L` の内部自由度 `α: L` と `β: L` を site `i` に配置した場合、具体的な因子を `(i,α)` と `(i,β)` として参照できる。この表記の α・β は説明用の記号であり、内部ラベル API や Index の値・生成方法を定めるものではない。実際の参照には因子の順序と保持した Factor を用いる。各基本因子は独立に発行した Index を持ち、参照時にはそれを保持する。

```text
局所複合構造                  Site 配置後
├─ α : 局所構造 L            ├─ (i,α) : L
└─ β : 局所構造 L            └─ (i,β) : L

大域の基本因子順序の例: (0,α), (0,β), (1,α), (1,β), ...
```

配置・モデル構築側が大域空間を新しく構成するときは、site と内部因子の対応・順序を明示して子空間列を指定する。既存空間を Site に割り当てる場合は、その因子順序を変更しない。core は木の子順序から基本因子の順序を確定し、元の grouping と基本因子の対応を保持する。この展開は空間の因子構造に対するものであり、状態・演算子の式、全基底、行列を全展開する操作ではない。

構築時に指定した内部自由度を利用する際は、元の Index と局所構造を保持する。そこに局所演算子を配置し、明示した大域空間へ埋め込むときに、基本因子との整合性を検証する。部分系の取得元や木の位置を記録する特別な対象は設けない。partial trace には構築時の空間を指定でき、その基本因子が全作用空間の部分系を構成することを検証する。

### 3.4. 検証条件

- 次元だけが同じ別自由度や異なる因子順序を暗黙に同一視せず、互換でない始域・終域の合成を拒否する。
- 構築時の基本自由度を配置・演算に再利用しても Index・局所構造が保持され、括り方の違いだけでは空間の互換性が変わらない。
- 部分系判定で Index・局所構造・相対順序・積の種類を検証し、連続しない因子の部分系、空間自身、および空の Tensor を認める。
- 空間・状態の tensor product で親と内部因子の重複を拒否し、演算子の積では同一因子への連続作用を許可する。
- 空間構造の展開が状態・式・全基底・行列の全展開を引き起こさない。
- 初期版では異種局所構造の混在・合成を型または構築時の検証で受け付けず、同じ局所構造の独立な因子に対する作用が共通機構の規約に従うことを確認する。独自代数の検証は、それぞれ別の系として行う。

## 4. 状態式・演算子式

### 4.1. 共通の式とスカラー

状態式・演算子式は core の builtin の型に統一する。ユーザは局所構造・primitive・局所演算規則・基底を追加でき、独自の primitive と規則の結果も builtin の式で扱う。式木の構文・共有・空間情報・評価手順は core が管理し、ユーザ独自の式木や節点を共通 evaluator へ接続する公開契約は設けない。

一つの局所構造の上の式にもこの共通の式木を利用し、primitive の積・作用・随伴の結果は同じ局所構造の primitive の有限線型結合として表す。共通機構は、必要な評価時に線型性・半双線型性・共役線型性に従って primitive の規則へ委譲する。数学的能力の担当と導出する操作は、[局所 primitive・式木の数学的能力](design/primitive-expression.md)に定める。

式の内容を保持する共通パーツは `ScaleExpr`・`SumExpr`・`ProductExpr`・`ActExpr`・`AdjointExpr` とし、局所式と複合式で再利用する。`LinearCombination<P, C>` は共通パーツで保持する薄い有限線型結合型として維持する。Product・Act・随伴の trait は係数全体 `C` を型引数、返却要素を関連型 `Term` とし、出力を `LinearCombination<Self::Term, C>` に限定する。Act の演算子型も関連型で指定し、数値制約は各実装に置く。局所規則・恒等演算子・局所基底展開の結果は、式木側が係数を保持したまま `map` で要素を変換し、共通 constructor で和・スカラー倍として取り込む。`map` 自体に要素・係数の `Clone` は要求しない。core・spin-half・テスト実装の関連型への移行と式木への接続は、実装計画の Step 2 で行う。

共通パーツは `expr::parts` で保持内容も公開し、式ハンドルを crate root から再公開する。節点 enum と共有の内部表現は非公開とする。項型 `Term<P, C>` は `ScaleExpr<P, C>` の別名に統合し、要素フィールド名を `operand` に揃える。関連型 `Term` は係数を含まない要素型として区別する。既存の線型結合の構築・走査 API を維持し、走査は `SumExpr` 側へ集約する。

式の保持・係数計算を伴わない遅延構築・map に数値制約を付けず、演算に必要な制約はメソッドごとに付ける。primitive の既存の最小限の数値制約を維持し、全能力をまとめた係数 trait は導入しない。式同士の二項演算子は所有値・借用値の4通りを提供し、所有ハンドルは移動、借用ハンドルは共有参照の複製で処理する。名前付きメソッドは共有借用を基本とする。

Builtin の式木の節点を列挙して評価を分岐することは許容する。線型構文の分解・分配・係数処理は内部機構で共用し、呼び出し順は builtin の評価実装が決める。

代数オブジェクトのスカラーは複素数に統一し、以下を扱う。

- 単精度複素数
- 倍精度複素数

実数値は、対応する複素数値に変換して受け入れてよい。代表ユースケースの `J` は具体的な複素数値として与える。

左 scalar multiplication と右 scalar multiplication は同じ意味とする。単精度と倍精度のオブジェクトを同じ演算で混在させず、暗黙の精度昇格も行わない。精度を変更する場合は明示的な変換を必要とする。

scalar の算術、厳密比較、丸め、NaN・正負の infinity などの特殊値の挙動は、採用する数値型に委譲する。型が表現できる値は受け入れ、qmb-rs 独自の正規化・拒否・例外化・置換・補正規則を設けない。5.6 節の明示的な近似比較と精度混在の検証は別の契約として定める。

局所規則による評価や基底展開は数学的な構造に従って行い、元の数値演算列の丸めや非有限値の伝播をそのまま再現する追加保証は設けない。

### 4.2. 状態式の構成と演算

状態は、数値ベクトルではなく、Index を付与した局所状態からなる代数的なオブジェクトとして表現する。状態の所属空間の確定と拡張は、5.1 節に定める。

状態式の表現要素として以下を扱う。

- 局所基底状態
- 基底積状態
- 一般の積状態
- 状態の有限線形結合

状態に対して以下の演算を提供する。

- 同一 Hilbert 空間上の二状態の加算
- 状態と複素 scalar の scalar multiplication
- 二状態の tensor product

状態の加算結果は、同じ Hilbert 空間上の状態の有限線形結合とする。同類項の結合および zero term の除去は、指定基底への展開や必要な評価の内部処理として行い、構築時に式全体の整理を要求しない。

tensor product の結果は、左 operand の自由度を左側、右 operand の自由度を右側に配置した複合状態とする。二 operand の基本因子が重複する場合、または scalar・grading・交換規則などの合成条件が互換でない場合はエラーとする。

未束縛の状態式だけから対象空間を一意に決められない場合は、検証または評価前に空間を確定する。一度空間が確定した状態は、評価・基底展開で zero となっても所属空間を失わない。

空間・状態の空の tensor product は scalar `1` とする。

### 4.3. 演算子式の構成と演算

演算子は、数値行列ではなく、primitive な局所演算子からなる代数式として表現する。局所式の配置と全 Hilbert 空間への埋め込みは、5.1 節に定める。

spin 系の演算子式の表現要素として以下を扱う。

- 恒等演算子
- 局所 spin 演算子 `Sx`, `Sy`, `Sz`, `S+`, `S-`
- 異なる site に作用する局所演算子の積
- 演算子項の有限和

演算子式に対して、以下の構築操作を提供する。

- 演算子式同士の加算
- 演算子と複素 scalar の scalar multiplication
- 演算子の通常の積

Adjoint および commutator は、写像の整理と汎用的な係数計算に関わる操作として設計に含める。指定基底への展開と必要時の評価は 4.4 節・6 節、状態への作用は 5.3 節、full trace と partial trace は 5.4 節に定める。

演算子の和と積は任意個の operand を扱い、積の入力順序を保存する。未束縛の演算子式は異なる自由度を参照していても形式的に合成できる。構文上の参照自由度は各 operand の和集合から導出できる。全 operand が束縛済みなら空間の互換性を検証し、一つでも未束縛なら作用空間を比較せず未束縛の結果を返す。子節点には operand の旧束縛を残さない。

演算子用の独立した tensor product 操作・節点は設けず、同じ自由度にも異なる自由度にも通常の積を用いる。Tensor product の種類と因子順序は Hilbert 空間から取得し、同じ自由度への作用は局所積の規則で処理する。積の構築で作用空間を自動合成しない。空間・状態の tensor product は別に提供し、基本因子の重複を拒否する。

`A * B` は数学的な積 `AB` を表し、状態には右側から作用する。

```math
(AB)|\psi\rangle = A(B|\psi\rangle)
```

したがって、`A * B` では `B` が先に、`A` が後に作用する。

異なる site に作用する spin 演算子は可換として正規化できる。同一 site 上の演算子については順序を保存し、局所 spin 代数に従って処理する。

演算子式が構文上参照する自由度は、配置済みの primitive に付与された Index や局所複合構造の分解から導出できるようにする。support または最小作用空間を、すべての複合式へ必須 metadata として保存することは要求しない。ただし、Fermion の parity string を含む表現では、構文上の参照自由度と通常の tensor 表現で非自明に作用する因子を区別する（5.5 節）。

### 4.4. Lazy な評価・基底展開と構造の共有

状態式の `act` は `Act` 節点で遅延した作用を構築し、`evaluate` は局所 primitive の規則と線型性・合成則に基づいて状態式を評価する。`ψ.act(&b).act(&a)` は `A(Bψ)` を表す。`evaluate` は基底を入力に取らず、選択基底への展開・座標化や行列の生成とは別の操作とする。

初期版では、この局所規則による評価に加え、指定した基底への展開と係数取得を提供する。分配だけ、局所積だけなど、特定の簡約ルールのみを選んで適用する独立した操作は 9.2 節の future work とする。

分配・局所積・係数の結合・zero term の除去は、基底展開や作用・内積・trace などに必要な内部処理として用いる。これらを個別に要求する操作を初期版に含めないことは、局所規則による評価を延期することを意味しない。

- 状態・演算子の加算、scalar multiplication、演算子の積、および空間・状態の tensor product の構築時に、式全体を eager に展開・評価しない。
- 未評価の代数構造を保持し、状態への作用、内積、trace、数値表現への変換、または指定基底への展開を要求した時点で、必要な部分だけを評価する。
- 評価に必要のない部分式を展開しない。
- lazy evaluation の有無によって、代数オブジェクトの数学的な意味が変化してはならない。数値的な一致の保証は 4.1 節および 5.6 節の規約に従う。

評価・基底展開は入力の式を変更せず、結果を通常の式として返す。評価前の式が必要な場合は利用者が保持し、結果へ元の式や履歴を自動的に付随させることは要求しない。基底展開の結果は選択した基底要素で表した通常の式木とし、同じ基底要素の係数をまとめる。結果の式木に基底識別情報や特別な展開済み状態は要求せず、通常の演算や別基底への再展開を適用できる。数値座標の取得では、その解釈に必要な基底・順序を別途確定する。随伴は operand を参照する遅延節点として保持でき、構築時に大きな式を複製しない。評価結果を保存・再利用するキャッシュ機構は 9.2 節の未決の future work とし、初期版に要求しない。

演算子積を常に完全展開すると項数が増大し得るため、評価に必要な局所処理や指定基底への疎な展開を必要に応じて導出し、すべての演算経路に共通の完全展開形を強制しない。作用・内積・trace は指定基底への展開を必須としない。積和から和積への因数分解は初期版の対象外とし、あらゆる式に対する最適な表現や計算量は保証しない。

状態、演算子、および Hilbert 空間の操作では、データのコピーを最小限に抑え、memory friendly な実装とする。

- 不変な Hilbert 空間情報、局所空間、基底情報、および代数式の部分構造を可能な限り共有する。
- 加算、演算子の積、scalar multiplication、および空間・状態の tensor product のたびに、変更されない operand 全体を複製しない。
- API の所有権設計では、参照、共有所有、move、view、または同等の仕組みを適切に用い、不要な deep copy を避ける。
- 密表現への変換を明示的に要求されるまで、Hilbert 空間の次元に比例する密な領域を確保しない。
- 一時的な中間状態および中間演算子の peak memory usage を抑える。

不変な式節点・primitive の共有は `Arc` を基本とし、共有の内部表現は非公開とする。primitive に一律の `Clone`・`Copy`・`Send`・`Sync`・`'static` を要求しない。`Arc` はポインタ幅の atomic 操作を持つ target を前提とするが、並列評価は初期版に要求しない。不変実体の共有は、評価結果を保存・再利用するキャッシュ機構とは区別する。

`Arc` は、式の合成や `Clone` で不変な部分式を共有するために用いる。同じ式ハンドルを再利用した `&a + &a` や `a.scaled(c)` は既存の実体を参照し、元の式を変更しない。節点の共有によって内部の primitive も共有できる。別々に構築した同形の式を自動検出して共有する機構は初期版に要求しない。

局所評価器は状態評価・演算子の作用・演算子項の走査を分担する。状態への作用評価に演算子の Product 能力を要求せず、局所積が必要な trace などで要求する。評価と最後の所有者になった式節点の破棄は明示的な作業スタックを使い、式の深さに比例した関数再帰に依存しない。長い積・作用のチェーンの評価・破棄と、共有先が残る部分式の保持を Step 2 で検証する。性能上の合格条件は共有、不要な primitive 複製の抑制、空・単一項のコンテナ無確保とし、map 全般の無確保や特定の実行時間は保証しない。

### 4.5. Source・構造比較・表示の延期

評価前の source expression の自動保持、式の構造比較、および式構造・基底展開結果の表示 API は後続へ延期する。現在の式と source を別々に保持する機構や、式表示のための trait 制約は初期版に要求しない。

入力の不変性と不変実体の共有は維持する。局所規則による評価に primitive や式の構造比較を必須とせず、同じ基底要素の係数は指定基底の順序番号に基づいてまとめる。

Index・局所構造・空間の整合性判定はこの延期に含めない。数値的近似比較と作用としての等価性は 5.6 節に従い、式構造の一致を前提としない。

### 4.6. 検証条件

- 演算子積が右側から作用する規約と一致する。
- 状態の加算、scalar multiplication、および tensor product が線形性と定められた因子順序を満たす。
- 演算子の加算・scalar multiplication の線形性と、任意個の積の各 operand に関する線形性、および定められた作用順序を検証する。
- operand だけで判定できる不正な状態和および空間・状態の tensor product が構築時にエラーとなる。
- 長い加算列や積の構築時に、式全体の展開・評価が eager に実行されないことを確認する。
- `act` のチェーンが遅延構築であり、`evaluate` が基底を指定せず局所規則で評価することと、作用順序を確認する。
- 評価・指定基底への展開が入力の式を変更せず、基底展開が基底要素ごとの係数をまとめることを確認する。source の自動保持・構造比較・表示、個別の簡約ルール適用は初期版の受入条件に含めない。
- 代表ユースケースにおいて、演算子の合成だけでは Hilbert 空間の次元に比例する密な領域が確保されないことを確認する。
- 代数式の合成時に、変更されない大きな部分構造が不要に deep copy されないことを確認する。

## 5. 埋め込み・評価

### 5.1. 配置、束縛、および評価空間の選択

演算子の構築と埋め込みは、次の三段階に分ける。

```text
局所構造の上の演算子・局所式
    → 自由度を指定した局所演算子による式
    → 指定した全 Hilbert 空間への埋め込み
```

Index を付与した未束縛の式は spectator を含む全作用空間を保持しない。空間依存の作用、trace、export の時点では、状態または明示的な埋め込みから全作用空間を確定する。束縛済み演算子はその始域・終域を参照できるようにする。

Index 未付与の局所式は一つの局所自由度に属するものとし、式全体に同じ Index を付与する。局所状態・演算子が元の局所構造を保持し、所属先・作用先の因子を Index で識別する。Index の付与では新しい Index を暗黙に発行しない。局所状態式は配置先の局所空間に属する。複数自由度の式はそれぞれ Index を付与した後で合成し、全作用空間への bind だけから primitive の配置先を推測しない。

局所演算子式と Index の組を複合演算子式の葉とし、状態側も局所状態式と Index の組から構成する。Index の付与を配置、全作用空間の確定を束縛と呼び分ける。演算子の埋め込みは線型結合・積・随伴・恒等演算子を保存する。詳細は [配置・埋め込みが保存する関係](design/composite-expression.md#4-配置埋め込みが保存する関係)に定める。

例えば `Sx_i + Sz_j` を `H_i ⊗ H_j ⊗ H_k` に埋め込むと、spin 系では `Sx ⊗ I ⊗ I + I ⊗ Sz ⊗ I` と解釈する。埋め込み自体は行列生成ではなく、元の式を共有したまま作用空間を確定できるようにする。

```math
|\psi\rangle:\mathbb C\to\mathcal H,
\qquad A:\mathcal H\to\mathcal H,
\qquad \langle\psi|:\mathcal H\to\mathbb C.
```

数学的な bra は Hilbert 空間の内積を用いて ket の随伴として得る。初期版では独立した bra 型・構築メソッドを導入せず、braket は内積で計算する。作用、内積、期待値を写像の合成として整理し、空間確定後の対象は正確な始域・終域を参照できるようにする。合成の接続先の互換性を検証する。

数学的に共通の整理を採用することは、利用者向けの型を同一にすることを要求しない。

空間が確定した状態は所属空間を参照できるようにし、未確定の状態式を評価する場合は明示的な埋め込み情報を与える。演算子の identity extension と異なり、新しい自由度を状態へ追加するには、その自由度の状態または明示的な埋め込み写像が必要となる。

複合演算子の指定基底への展開には束縛先または動的に明示する Hilbert 空間を必要とし、参照因子だけから全作用空間を推論しない。spin 系の評価時にはその空間へ恒等演算子で拡張し、Fermion では 5.5 節の grading に従った埋め込みを用いる。

束縛・基底展開・作用・trace に空間を明示した場合、未束縛・束縛済みを問わず指定先を優先し、旧束縛先との一致は要求しない。指定先で参照自由度と局所構造の整合性を検証し、元の式を変更しない。

空間を省略した場合は既存の束縛先を用い、未束縛演算子の作用だけは状態の所属空間を用いる。複合演算子の基底展開・trace で束縛も明示空間もなければエラーとする。

式を返す操作は選択した空間を結果に保持し、partial trace は残存空間を保持する。作用では選択した空間と状態空間の互換性を検証し、状態の所属空間を暗黙に変更しない。

演算に用いる数値精度と合成規則は互換でなければならない。式が参照する自由度の存在と、その因子の局所構造との整合性を検証する。判定できる情報が構築時にある場合は早期に検証し、全作用空間に依存する条件は埋め込み・評価時にも検証する。

### 5.2. Zero、identity、および scalar の解釈

zero と identity は、空間が確定した対象として始域・終域を保持する。zero map は `0_{U→V}: U→V`、identity は `I_H: H→H`、zero state は `0_{C→H}` として整理する。評価・基底展開の内部処理で zero term や identity factor を除去しても、その操作で選択した空間と結果の始域・終域を失ってはならない。

埋め込み前の式に現れる空間未確定の `0`・`1` は、埋め込み先に応じて解釈する記法として扱える。対象空間を式から推論できない場合は、評価前に明示的な埋め込みを必要とする。

primitive な局所演算子を含まない scalar `c` は、評価対象の Hilbert 空間 `H` 上では

```math
c I_{\mathcal H}
```

として解釈する。scalar `0` は zero operator、scalar `1` は identity operator に対応する。演算子の空和・空積はそれぞれ zero・identity とし、明示した作用空間を保持する。

### 5.3. 行列化しない作用・内積・期待値

内積、norm、演算子の状態への作用、期待値、および正規化期待値は、状態式を入力とする評価操作として扱う。norm は Hilbert 空間の内積に基づく `sqrt(<ψ|ψ>)` とし、grading の導入だけで内積や norm の定義を変更しない。

演算子の状態への作用を、行列化しない計算の基本操作とする。

```math
|\phi\rangle = A|\psi\rangle
```

期待値は、この作用と内積を用いて

```math
\operatorname{expectation}(\psi,A)
= \langle\psi|A|\psi\rangle
= \langle\psi|\phi\rangle
```

と定義する。これは正規化されていない状態に対しても、式どおりの値を返す。

正規化期待値は別の操作として

```math
\operatorname{normalized\_expectation}(\psi,A)
= \frac{\langle\psi|A|\psi\rangle}
       {\langle\psi|\psi\rangle}
```

と定義する。zero-norm state に対する正規化期待値の計算はエラーとする。

以下を満たすことを要件とする。

- 代数的な演算子の状態への作用に、完全な演算子行列を必要としない。
- 代数的な内積と期待値の計算に、密行列または疎行列への変換を必要としない。
- 積状態や局所演算子に対する局所的な因子分解は、将来の拡張時に上記の意味論を維持する必要がある。初期版の積和から和積への因数分解は対象外とする。

一般の線形結合状態への作用では、状態を構成する項数が増大する可能性がある。あらゆる入力に対して Hilbert 空間の次元によらない計算量は保証しない。

### 5.4. Full trace と partial trace

演算子 `A` の full trace は、埋め込みによって確定した有限次元 Hilbert 空間 `H` 上で

```math
\operatorname{Tr}_{\mathcal H}(A)
= \sum_k \langle e_k|A|e_k\rangle
```

と定義する。ここで `{|e_k>}` は `H` の任意の完全正規直交基底である。full trace は非正規化 trace とし、複素 scalar を返す。trace の値は基底の選択に依存してはならない。

trace は代数的な演算として提供し、完全な密行列または疎行列の生成を必要としてはならない。局所演算子の tensor product に対しては、可能な場合に

```math
\operatorname{Tr}(A \otimes B)
= \operatorname{Tr}(A)\operatorname{Tr}(B)
```

を利用できるものとする。

partial trace の計算時には、次の二つを確定する。

- `ambient`: 明示した空間があればそれを優先し、なければ入力演算子の束縛先を用いる全 Hilbert 空間
- `trace_out`: trace out する空間。空間の基本因子から縮約対象の自由度集合を取得する

`trace_out` は、3.2 節の条件で `ambient` の部分系でなければならない。構築時に指定した内部自由度の空間を利用でき、site 全体の指定はその構成因子の空間に対応づける。演算子式が参照するすべての自由度も `ambient` に存在しなければならない。未束縛式でも空間引数を与えれば処理でき、先に別の束縛操作を呼ぶ必要はない。束縛も明示空間もなければエラーとし、縮約対象から ambient を推論しない。束縛済みでも `trace_out` は別途指定する。

結果は残存空間 `R` に束縛された演算子 `B: R→R` とし、残存因子の Index・局所構造・順序を保存する。結果が zero または scalar identity でも `R→R` を保持する。呼び出し側に結果の再埋め込みを要求しない。式には今回選択した縮約前の `ambient` と縮約対象を記録した遅延節点を保持できる。結果の束縛先を後から上書きしても、既存節点の縮約前空間は変更しない。

演算子が trace out する自由度上で恒等的に作用する場合、その局所空間の次元を係数へ掛ける。特に、

```math
\operatorname{Tr}_{\mathcal H_1}
\left(A_0;\mathcal H_0\otimes\mathcal H_1\right)
= \dim(\mathcal H_1)A_0
```

とする。空集合を trace out する場合は元の演算子と等価な式を返す。すべての自由度を trace out する場合、partial trace の結果は 0-site Hilbert 空間上の scalar operator expression とする。full trace は同じ数学的結果を複素 scalar として返す。

Fermion を含むすべての系で、full trace と partial trace は通常の Hilbert 空間上の非正規化 trace とする。partial trace は、入力の埋め込みで確定した因子順序と通常 tensor 表現に対して定義する。残存因子の基底 index を `r,r'`、trace-out 因子の完全正規直交基底 index を `t` とすると、結果の行列要素は `B_{r,r'} = Σ_t A_{r,t;r',t}` である。ここで複合 index は元の因子順序に従って配置し、この定義のために行列を生成する必要はない。

Fermion の場合は入力の ordering と grading を参照し、parity string を含む実際の作用に従って処理する。単に trace-out した自由度のラベルを消して元の式を再埋め込みしてはならない。supertrace は現時点では扱わず、graded な縮約によって通常の trace の意味を変更しない。

構文上の参照自由度を、通常 tensor 表現での作用因子と同一視しない。例えば二 mode の `c_1=P_0⊗a_1` について、通常の行列上の partial trace は

```math
\operatorname{Tr}_0(c_1)=\operatorname{Tr}(P_0)a_1=0
```

となる。mode 0 を identity spectator として `2a_1` を返すのは誤りであり、結果は残存空間 `H_1→H_1` の zero operator となる。これは 5.4 節で採用した通常の partial trace の規約に従う。

Spinful fermion で up mode だけを partial trace する場合は内部 mode の参照を、site 全体を指定する場合は両因子を用いる。

Partial trace は線型性と随伴を保存し、残存空間でさらに full trace を取ると元の full trace に一致する。互いに重ならない因子集合の逐次縮約は、同じ対象をまとめた縮約と一致する。これらと埋め込みの整合性は、[full trace・partial trace の契約](design/composite-expression.md#7-full-tracepartial-trace-と埋め込み)に定める。

### 5.5. 因子間の grading と通常 tensor 表現への埋め込み

異なる基本因子の間の符号は共通の複合代数機構が担当し、埋め込み context が因子順序を提供する。局所複合代数の内部と site 間の合成にも同じ機構を使用し、幾何構造に符号処理を担当させない。

異なる因子上の parity が確定した演算子と、graded tensor product の積は次の規則に従う。

```math
A_iB_j=(-1)^{p(A)p(B)}B_jA_i,
\qquad
(A\otimes_g B)(C\otimes_g D)
=(-1)^{p(B)p(C)}AC\otimes_g BD.
```

混合 parity の和は成分ごとに扱う。homogeneous な因子積の parity は各因子の parity の和 modulo 2 とする。積だけでなく作用・随伴についても、合成規則に整合する処理を行う。

複合空間の作用・tensor の随伴は、[ordinary / graded の合成則](design/composite-expression.md#5-ordinary--graded-の合成則)に従う。Graded な空間の even・odd 部分は直交し、積状態の内積には通常の正定値な tensor product の内積を用いる。合成則は入れ子にも同じように適用し、同種の積の括り方だけで符号や数学的結果を変えない。通常の演算子積では graded でも `(AB)† = B†A†` とする。

通常の tensor product・行列として評価する経路は、次のように責任を分ける。

```text
tensor ordering と grading 規則から parity 演算子を挿入
    → 基本局所代数で局所積・作用を評価
    → 残った parity 演算子を保持、または必要に応じて評価
```

intrinsic な graded 表現では符号を直接処理できる。parity string に変換済みの符号を再び graded 交換規則で適用してはならない。計算表現を明確にし、各経路で同じ作用を保存する。

Jordan–Wigner の例として、空状態を `|0>`、占有状態を `|1>`、局所消滅演算子を `a=|0><1|` と定める。この規約では `P=(-1)^n=Z=diag(1,-1)` であり、

```math
c_j=P_0\otimes\cdots\otimes P_{j-1}
\otimes a_j\otimes I_{j+1}\otimes\cdots.
```

`i<j` の通常の積 `c_i c_j` の局所因子は、`k<i` で `I`、`k=i` で `a_iP_i`、`i<k<j` で `P_k`、`k=j` で `a_j`、`j<k` で `I` となる。二つの global operator の tensor product ではない。この局所規約では `aZ=-a` である。

中間領域には一般に次の parity が残る。

```math
P_{(i,j)}=\prod_{i<k<j}P_k=(-1)^{\sum_{i<k<j}n_k}.
```

占有数基底への作用は占有数から符号を評価できる。重ね合わせでは成分ごとの作用を必要とし、状態全体を定数の符号へ置換できるのは対応する parity の固有状態である場合に限る。区間 parity を未評価の構造として保持できる設計を検討する。

spinful fermion を通常 tensor 表現で site 間に埋め込む場合、内部 CAR を満たす局所演算子 `f_{i,σ}` に先行 site の総 parity を掛ける。

```math
c_{i,\sigma}=\left(\prod_{j<i}P_j\right)f_{i,\sigma}.
```

site 内と site 間で符号を重複適用しない。

### 5.6. 数値的近似等価性と検証の規約

数値的近似等価性は、対応する数値が指定された許容誤差の範囲で一致することとする。作用としての等価性は、同一の Hilbert 空間上で同じ線形作用を表すこととする。

近似比較には、絶対許容誤差 `atol` と相対許容誤差 `rtol` を用い、複素数 `a`, `b` に対して

```math
|a-b| \leq \mathrm{atol}
       + \mathrm{rtol}\max(|a|,|b|)
```

を満たす場合に近似的に等しいと判定する。

近似等価性は推移律を満たさないため、通常の厳密な等値判定とは別の明示的な操作とする。NaN を含む値は、自身を含めて近似的に等しいと判定しない。作用としての等価性の検証には、小規模系の数値表現を基準にできるものとする。

テストでは、検証に使用した `atol` と `rtol` を明示する。数値比較と rank 判定の許容誤差は数値精度と計算規模に応じて設定し、独立に定義した小規模系のベクトル・行列による参照計算と比較する。検証用の許容誤差を通常の式評価での zero term の削除に使わない。

### 5.7. 検証とエラー検出の時点

operand および構築時に与えられた情報だけで判定できるエラーは、原則として式の構築時に検出する。代表例として、互換でない Hilbert 空間に属する状態同士の加算、および同じ Index を含む空間・状態の tensor product がある。同一自由度上の演算子積はエラーではなく、4.3 節の規約に従って許可する。

一方、lazy な式では、構築時点で未評価の部分式や、後から与えられる Hilbert 空間または評価 context に依存しなければ判定できない条件がある。このため、基底展開時または評価時にもエラーを検出し得るものとする。同種の不正な式について、構築時に判定可能であれば早期にエラーを返し、構築時に判定できなければ基底展開時または評価時にエラーを返す。

少なくとも以下を検出してエラーとして扱う。

- 演算子式が参照する自由度を含まない状態または評価 context 上での作用、trace、または数値化
- 状態・演算子が指定する局所代数と、参照する因子に割り当てた局所構造が一致しない場合の演算または評価
- 互換でない Hilbert 空間に属する状態同士の加算または内積
- `trace_out` が `ambient` の部分集合でない partial trace
- zero-norm state に対する正規化期待値の計算
- 単精度と倍精度を混在させた代数演算
- 束縛済みの対象で、始域・終域が互換でない加算・合成

本章の検証条件は以下とする。

- 異なる自由度を参照する演算子の和が、評価 context 上で適切に identity extension される。
- 演算子の積が同一・異なる自由度の両方を扱い、評価空間の種類と因子順序に従って合成される。
- 恒等演算子の trace が Hilbert 空間の次元と一致する。
- 局所 spin 演算子 `Sx`, `Sy`, `Sz` の trace が 0 となる。
- tensor product の trace が各因子の trace の積と一致する。
- 代数的に求めた trace が、密表現および疎表現から求めた trace と一致する。
- Spin 系で恒等的に作用する自由度を trace out したとき、その局所次元が係数へ掛けられる。Fermion では構文上の support だけで spectator と判定しない。
- 空集合、真部分集合、および全自由度に対する partial trace が定められた結果を返す。
- 一般の積状態と有限線形結合の内積・norm・作用を、基底積状態に限らず検証する。
- 未正規化期待値と正規化期待値を区別し、後者が zero-norm state を拒否する。
- Zero・identity が評価・基底展開後も始域・終域を保持し、0-site 空間が一次元、空積が scalar 1、`Tr(I_∅)=1` となる。
- Partial trace が残存順序と空間を保持する束縛済み演算子を返し、zero・scalar 結果も同じ契約に従う。
- 束縛・基底展開・作用・full/partial trace で明示空間が旧束縛先を上書きし、元の式を変更せず指定先の整合性を検証する。未束縛時の作用は状態空間を使い、複合演算子の基底展開・trace は束縛も明示空間もない場合を拒否する。
- 構築時には判定できない不正な式が、必要な情報を得た基底展開時または評価時にエラーとなる。
- 近似比較が式構造の一致を前提とせず、NaN を含む近似比較が自身を含めて false となる。
- 結果の要求時に、必要な部分式だけが評価されることを確認する。
- lazy な代数計算と、小規模系を完全に具体化した計算の数学的な作用が一致することを確認する。数値比較は明示した許容誤差で行う。
- 埋め込み前の式と束縛済み演算子の作用が一致し、異なる自由度の形式的な和を正しく評価できる。
- 内部因子または site 全体を指定した partial trace が同じ分解情報を用い、残存基本因子に束縛した結果を返す。
- 単一 mode と異なる mode の CAR、因子交換の符号、離れた mode の parity string を検証する。
- 占有数基底と重ね合わせへの作用、階層的な合成と基本因子列による合成の一致を検証する。
- Graded な計算と通常 tensor 表現への変換で同じ作用が得られ、符号が二重適用されない。
- Spinful fermion の内部 CAR、二重占有への作用、site 総 parity、mode 表現と site 表現の基底対応を検証する。
- Parity が作用する因子を identity spectator と誤認せず、二 mode の `Tr_0(c_1)=0` と、残存空間に束縛された zero operator の返却を検証する。
- Fermion の代数的な full/partial trace が、同じ埋め込み・因子順序による密表現の通常の full/partial trace と一致することを検証する。

## 6. 基底・export

### 6.1. 状態基底と演算子基底

状態基底と演算子基底は、それぞれ指定した状態空間と演算子空間の順序付き座標系として扱う。局所基底要素は対応する primitive の部分集合とし、対象空間全体に線型独立かつ完全であることを要求する。primitive の一覧全体が独立な基底であるとは限らない。

基底の定義を表す struct が対象の要素型を指定した `Basis<P, C>` を実装する。primitive の基底展開、基底要素である primitive の順序番号の取得、および基底順序での遅延列挙を提供する。状態 primitive の展開は `LinearCombination<S, C>`、演算子 primitive の展開は `LinearCombination<O, C>` を返し、要素は選択した基底の primitive に限る。式木側は `map` と共通 constructor で通常の式へ取り込む。基底要素でない primitive は展開できるが、それ自体を指す順序番号は持たない。局所基底と式木の接続は Step 2 に含める。数学的な契約は [基底の数学的能力](design/basis.md)に定める。

Step 2 では `Basis<P, C>` を維持し、`StateBasis`・`OperatorBasis` は削除する。利用側は状態基底には `Basis<S, C>`、演算子基底には `Basis<O, C>` を直接要求する。`index() -> Option<usize>` と所有要素の遅延列挙を維持する。次元取得 API からは不要な型引数 `T` を外し、完全性・線型独立性・状態で `d`、全演算子空間で `d²` という要素数の契約と検証条件を維持する。

考えている演算子空間の基底を構成・列挙できることを必要とし、次の機能を設計に含める。

- 各基本因子の局所状態基底・局所演算子基底から tensor product 基底を構成する。複合基底はこの合成に限定し、複数因子をまとめた独自の基底は扱わない。
- 基底の順序、局所構造から導出した要素数、順序番号による要素参照、遅延列挙を扱う。番号から要素を得る操作は列挙から導出でき、Basis の必須の独立能力にはしない。
- 全状態空間・全演算子空間に対して線型独立かつ完全な基底を扱う。
- 正確な基底展開と係数取得を扱う。式の表現に用いる基底の変更は、別基底への再展開で行い、独立した基底変更機構は設けない。初期版では部分空間基底・射影を提供しない。
- 正規直交性を要求せず、展開の実装には内積、Gram 行列や双対基底などを利用できる。

基底要素数は、対応する局所構造の Hilbert 空間次元を `d` としたとき、状態基底では `d`、全演算子基底では `d²` と導出する。Basis に独立した要素数の提供を要求しない。列挙は基底要素を一度ずつ返し、その個数は導出した要素数に一致する。列挙の第 `k` 要素の順序番号は `k` とし、同じ基底定義・パラメータのもとで順序を一致させる。

座標取得は Basis の分解規則を用い、core が線型性によって式全体へ拡張する。内積、Gram 行列、双対基底は分解規則の実装手段であり、Basis の必須の独立能力にはしない。演算子内積を使う場合は、非正規化の Hilbert–Schmidt 内積 `⟨A,B⟩ = Tr(A†B)` とし、Hilbert 空間の次元による除算は行わない。必要な場合には局所基底の Gram 行列に対する線型方程式を解くことができる。このために大域の状態ベクトル・演算子行列を生成することは要求しない。

spin-1/2 では `{I,Sx,Sy,Sz}` と `{I,S+,S-,Sz}` は全演算子空間の基底になり得るが、`{Sx,Sy,Sz}` は identity を表現できず、初期版の基底の契約を満たさない。指定基底への展開は、式を整理する明示的な操作と、行列表現などの座標取得に用いる。通常の作用・内積・trace に基底展開を必須とせず、指定基底による正確な展開で成分を黙って捨てない。

基底を列挙できることは全要素を一度に materialize することではない。`N` 個の spin-1/2 の全演算子基底は `4^N` 要素となるため、部分参照・遅延列挙・必要な成分だけの計算を基本とする。

計算の入力基底と出力基底は異なってよいが、それぞれの全対象空間に完全なものとする。局所基底の展開規則は任意の primitive を選択基底の有限線型結合へ変換し、共通機構が通常の局所式へ取り込む。基底要素の配列を入力することは要求しない。基底 primitive の共有実体を保持する実装では、その共有を取り込み後の式でも利用できるようにする。

展開結果は通常の式木とし、選択基底の識別情報や展開済み状態を保持させない。入力の式は変更せず、結果は Index・局所構造・確定した空間を保持する。別基底への再展開は前の基底情報を必要とせず、直接の展開と数学的に同じ座標を得る。数値係数列・行列の基底情報は、その座標を解釈するために別途確定する。詳細は [展開結果の契約](design/basis.md#52-展開結果は通常の式木とする)に定める。

Fermion の全局所演算子空間の次元は一 mode で 4、二 mode で 16 となり、後者には odd と even の両方が含まれる。初期版の基底はその全空間に完全とし、even 部分空間などへの制限は扱わない。

### 6.2. Tensor product の基底順序

`N` site 系の Hilbert 空間を

```math
\mathcal H = \mathcal H_0 \otimes \mathcal H_1
\otimes \cdots \otimes \mathcal H_{N-1}
```

とし、site 0 を tensor product の最も左側に置く。複合基底状態は

```math
|s_0,s_1,\ldots,s_{N-1}\rangle
= |s_0\rangle\otimes|s_1\rangle\otimes\cdots
\otimes|s_{N-1}\rangle
```

とする。

数値表現では、右端の site の局所基底 index が最も速く変化する。site `i` の局所次元を `d_i`、局所基底 index を `s_i` としたとき、global basis index を

```math
\operatorname{index}(s_0,\ldots,s_{N-1})
= \sum_{i=0}^{N-1} s_i \prod_{j=i+1}^{N-1} d_j
```

と定める。

spin-1/2 の二 site 系では、基底順序は次のとおりとなる。

1. `|up, up>`
2. `|up, down>`
3. `|down, up>`
4. `|down, down>`

ここで実際の zero-based global basis index は順に `0`, `1`, `2`, `3` である。密表現と疎表現は同じ基底順序を使用する。

局所複合構造を基本因子へ展開する場合は、展開後の因子列に同じ mixed-radix 規約を適用する。上記の site 単位の記述は一 site に一つの spin 因子を持つ標準例である。別の状態基底を選ぶ場合も、その順序と変換を明示し、同じ基底を指定した密・疎 export は一致させる。

複合基底は基本因子ごとの局所基底を Hilbert 空間の因子順序で合成し、Grouping は括り方だけを表して基底・座標を変えない。要素数は局所基底要素数の積とし、空の tensor product の基底は `{1}`、単因子の場合はその局所基底とする。Graded な演算子基底の合成は 5.5 節の規則に従い、独立した演算子 tensor product 操作は追加しない。

spinful fermion では、表示上の四次元基底と展開した二 mode の基底の対応を保持する。基底の表示順序と基本因子の順序は区別し、必要な座標変換を明示する。

### 6.3. 写像の表現行列と再利用可能な係数

再利用可能な係数データは、写像に入力・出力基底を指定した表現行列として整理する。ある演算子 `A` を固定した `T(ψ)=Aψ`・`T(X)=AX`・`XA`・`AX−XA`、固定状態 `ψ` に対する `T(A)=Aψ` などを対象とする。固定とは、その写像の入力変数として扱わないことを意味し、特別な演算子や状態の種類を導入しない。線型写像では以下の列が入力基底要素への作用の出力座標を表す。

```math
T(B_\mu)=\sum_\rho M_{\rho\mu}F_\rho.
```

各入力について線型か共役線型かを明示し、前者は係数列をそのまま、後者は複素共役して用いる。複数入力では、入力引数の指定順序でそれらの係数列の tensor product を取り、入力の複合 index を一つの列番号にまとめた表現行列を適用する。最後の入力の基底 index が最も速く変化する。

二つの可変演算子の積は双線型、adjoint は共役線型、内積は第一入力に共役線型・第二入力に線型とする。行ベクトルにするだけでは共役は入らないため、転置と共役転置を区別する。出力が状態の場合は状態基底、演算子なら演算子基底、scalar なら `C` の基底 `{1}` を用いる。非正規直交基底でも出力の展開座標を求め、単なる内積値と混同しない。

入力基底の列挙・通常の演算・指定出力基底への展開と係数取得を組み合わせる共通操作として提供し、専用 trait の実装は要求しない。写像の各入力の線型性／共役線型性は、演算を与える側が満たす数学的契約とし、基底への作用だけから推測しない。必要な列・成分だけを計算でき、行列や全演算子基底の積テーブルの一括生成は要求しない。詳細は [写像の表現行列](design/representation-matrix.md)に定める。

### 6.4. 密・疎の数値表現への変換

以下の四つの変換を提供する。

- 代数的な状態から密ベクトルへの変換
- 代数的な状態から疎ベクトルへの変換
- 代数的な演算子から密行列への変換
- 代数的な演算子から疎行列への変換

変換処理は代数 core から分離し、代数オブジェクトの意味を変更してはならない。export 先の密・疎ベクトルおよび行列表現は外部ライブラリの数値表現を利用する。6.2 節を既定の基底順序とし、別の基底を選択する場合も密・疎表現に同じ規約を適用する。

数値表現とともに、使用した始域・終域、因子順序、状態基底、および数値精度を確認できるようにする。

この数値表現の解釈に必要な情報は、通常の式木に基底識別情報を保持させる要求とは区別する。

行列の座標を定めるのは始域・終域の状態基底であり、演算子基底への全展開は必須ではない。正規直交基底では次の成分を用いる。

```math
A_{mn}=\langle e_m^{\mathrm{out}}|A|e_n^{\mathrm{in}}\rangle.
```

局所行列の Kronecker product、入力基底への作用から列を生成する方法、演算子基底展開などを選べる。非正規直交基底では双対基底などによる座標取得を必要とし、上式をそのまま一般化しない。

係数データ、直接微分可能な ML module、tensor network・MPS・MPO への export に拡張できるようにする。局所演算子積の有限和、内部分解、grading などの情報を不要に失わず、数値表現を経由することを必須としない。

疎表現への変換では、可能な限り密表現を中間生成せず、代数表現から直接構築する。

少なくとも以下を検出してエラーとして扱う。

- 基底順序を確定できない状態または演算子の数値表現への変換
- 指定基底の span 外の成分を、正確な係数展開として黙って破棄する操作

### 6.5. 外部ライブラリと自動微分との境界

代数 core は、空間・基底・式の構造、埋め込み、代数計算、および再利用可能な係数データの生成を担当する。係数の数値表現、自動微分、および export 先の数値表現は外部ライブラリに委ねる。接続時には、始域・終域、因子順序、基底、精度、およびパラメータ依存性を保存する。

将来の tensor network export でも、backend の縮約規約との違いを処理し、5.3–5.4 節に定める Hilbert 空間の内積・norm、および通常の trace と作用を保存する。

シンボリックに簡単に計算できることと、自動微分可能であることは別の要件である。ライブラリはパラメータ非依存の代数計算と再利用可能な係数データを構築し、外部ライブラリへ接続できるようにする。core 自体の自動微分機構は要求しない。

将来の微分可能 module 生成では、外部ライブラリのパラメータ依存性を保持し、通常の数値への変換で計算グラフを切らない。現在値が zero であってもパラメータ依存の項を無条件に削除しない。

### 6.6. 検証条件

- 二 site spin-1/2 系の基底順序が 6.2 節の規約と一致する。
- 状態の密表現と疎表現が近似的に一致する。
- 演算子の密表現と疎表現が近似的に一致する。
- 密表現から求めた期待値が代数的に求めた期待値と一致する。
- 疎表現から求めた期待値が代数的に求めた期待値と一致する。
- 単精度および倍精度のそれぞれで、適切な許容誤差を用いた検証が成功する。
- 単精度・倍精度の混在と暗黙の昇格を拒否し、明示的な精度変換を検証する。
- 非既定の基底を提供する場合は、その順序と座標変換、および export の空間・基底・精度情報を検証する。
- 演算子基底への全展開を経由しない export と、基底展開を用いた経路の結果が一致する。
- 疎表現への変換に密表現の中間生成が不要であることを確認する。
- 基底の順序、index、遅延列挙、係数取得、および係数からの再構成を検証する。
- 全対象空間に対する基底の独立性・完全性と分解・再構成を検証し、成分を黙って失わない。
- 非正規直交基底では Gram 行列・双対基底を用いた座標と内積の計算を検証する。
- 同じ全対象空間の異なる入力・出力基底で、同じ作用を表現できる。
- 小規模 spin 系で、係数 map と直接の代数・行列計算による作用・交換子が一致する。
- 写像の表現行列について、共役線型・双線型・半双線型な作用を虚部のある入力係数で検証し、共役指定と複数入力の列順序が正しく反映されることを確認する。
- 展開結果が基底情報なしの通常の式として利用でき、別基底への再展開が直接の展開と数学的に一致することを確認する。
- Tensor product 基底の要素・座標が grouping に依存せず、空・単因子の規約と一致することを確認する。
- 基底係数と Gram 行列から求めた内積・norm が、直接の代数計算と一致する。
- ML module を提供する場合はパラメータ依存性の保持を検証し、静的な係数データと外部ライブラリの可変パラメータを区別する。

## 7. 幾何・モデル構築

### 7.1. 物理空間と関係

物理空間は、自由度を置く場所と、それらの間に存在する幾何学的関係を表す。物理空間そのものは、各 site が spin、fermion、または別種の自由度を持つかを決定しない。

機能要件は以下である。

- 有限個の site
- 構築後に不変な Site の位置番号
- site の明示的な順序
- 一次元 chain
- open boundary condition
- periodic boundary condition
- nearest-neighbor 関係
- 関係の列挙

Site は Chain が保持する外側の Vec の位置を表す usize で指定し、構築後に順序を変更しない。専用の SiteId や所属トークンは導入せず、Chain を跨ぐ同一性・混用を管理しない。範囲外は検出する。詳細は [Chain・Site と自由度の配置](design/geometry.md)に定める。

一次元 chain は、一般的な site 集合と関係からなる物理空間を構築するための便利な生成手段として位置づける。幾何学的な関係と Hamiltonian の結合は同一視しない。物理空間は関係を提供し、モデル構築処理がその関係に演算子と係数を割り当てる。

向きのない二 site 関係は、明示された site ordering において先に現れる site を `min(i,j)`、後に現れる site を `max(i,j)` として、常に `(min(i,j), max(i,j))` の形へ正規化する。関係を列挙するときは、正規化した第一要素、第二要素の順に site ordering に基づく辞書順で並べる。

将来、三体相互作用、plaquette、および hyperedge を表現できるように、関係の概念を単純な最近接ペアだけに不必要に固定しない。

物理的な幾何構造、site への自由度の配置、演算子の作用構造、tensor network などの計算の接続構造を区別する。幾何構造はプログラムの実行や演算子式から暗黙に推論せず、ライブラリ内の明示的な対象として管理する。site ordering、tensor ordering、Fermion の mode ordering は、対応を明示して扱う。

### 7.2. Chain と boundary condition

Open chain の nearest-neighbor 関係は、長さ `N` に対して次のように定める。

```text
(0, 1), (1, 2), ..., (N - 2, N - 1)
```

Periodic chain では、次の規約を採用する。

通常は open chain の関係に `(N - 1, 0)` を加える。ただし、nearest-neighbor 関係は 7.1 節の規約に従って正規化された、向きのない一意な site 対として扱い、self-loop および重複辺を生成しない。

小規模系の規約を次のように定める。

- `N = 0`: 空の chain を許可し、nearest-neighbor 関係は存在しない。
- `N = 1`: self-loop を生成せず、nearest-neighbor 関係は存在しない。
- `N = 2`: `(0, 1)` の一つだけを nearest-neighbor 関係とする。

したがって、periodic boundary condition は多重辺を持つ周期格子としてではなく、単純な無向グラフとして解釈する。

### 7.3. 自由度の配置とモデル構築

Chain は局所代数に依存せず、Site ごとの Index 列 `Vec<Vec<I>>` と境界条件を直接保持する。Geometry 構造体は廃止し、各 Site の部分空間・全 Hilbert 空間・grouping を保持しない。構築経路は Site ごとの既存の所有 Index 列を渡すものと、Site 数・各 Site 共通の自由度数から Index を発行するものの二つとする。

構築時は `I: Eq` で Site 内・Site 間の Index 重複を拒否する。所有入力を移動して取り込め、保持・借用列挙には Clone・Default を要求しない。新規発行時のみ `I: Default` を要求して `I::default()` を呼び、この用途の Default は新しい独立した Index を発行する契約とする。所有データの複製や、借用 Index から別の Factor を構築する操作にだけ Clone を要求できる。Clone／Copy は同じ識別値の複製であり、新規発行ではない。Chain は UUID や具体的代数の規則に依存しない。

別の Chain や空間で同じ Index を再利用できる。全空間との対応・未配置・必要数に対する過不足は、その空間と接続するモデル構築側・利用側が検証する。空間の構築・保持・因子順序・grouping・局所式の配置と束縛も利用側が担当する。Site 順と全空間の因子順序は異なり得るものとし、既存空間の順序・grouping を暗黙に変更しない。接続時に Index を再発行しない。

空間への変換能力は独立した拡張 trait `ToSpace` と `to_space` メソッドで提供する。Chain では `I: Clone + Eq` を変換実装にだけ要求し、元の対象を借用して同じ Index を持つ空間を Site 順・Site 内の Index 順で構築する。同じ Arc 節点の返却は保証せず、生成した空間は利用側が保持する。Grading に必要な情報の渡し方は fermion 系の実装時に具体化する。詳細は[ToSpace の契約](design/geometry.md#61-空間への変換能力-tospace)に従う。

Site 数ゼロと自由度数ゼロの Site を認め、それぞれ空の外側 Vec・空の内側 Vec で表す。空 Site を削除したり、入力不足から暗黙に補ったりしない。単位空間や空 Tensor は必要な利用側が構築する。配置は構築後に不変とする。Chain 内の自由度は Site の位置と Site 内の Index 順序で参照し、内部ラベルは導入しない。

Chain は近接 Site ペアを列挙する。関係ごとの trait を設け、NearestNeighborRelation の `nn_pairs()` は Site 間の Index 全組合せ、`nn_pairs_by_pos()` は同じ位置同士を短い方まで借用列挙する。片側が空ならペアなしとし、Site ペア順と Site 内の Index 順序を維持する。相互作用項の演算子・係数の選択はモデル構築側が行う。構築・列挙・空間接続の契約は [Chain の設計](design/geometry.md)に従う。Step 4 の空間保持 API は移行前の記録とする。

XYZ Hamiltonian は `−Σ(Jx Sx_i Sx_j + Jy Sy_i Sy_j + Jz Sz_i Sz_j)` の負符号の規約とし、Heisenberg Hamiltonian は `Jx = Jy = Jz = J` の等方的な特別例として構築する。いずれも特別な内部表現を持つ演算子型とせず、一般的な局所演算子積の有限和として表現する。nearest-neighbor 関係に演算子項を割り当てるモデル構築用の便利な処理を、その一般表現の上に提供できるものとする。

Neel 状態は専用の状態型とせず、site ごとに局所状態を交互に割り当てた積状態として表現する。Neel 状態を作る便利な構築処理を提供することは妨げない。先頭 site を `|up>` とするか `|down>` とするかは構築時に指定できる。Heisenberg・Neel utility は各 Site に一つの spin Factor を持つ配置を対象とし、空 Site・複数自由度の Site はエラーとする。0-site では単位状態と zero Hamiltonian を構築する。

少なくとも以下を検出してエラーとして扱う。

- 存在しない site への局所状態または演算子の配置
- 一つの積状態における、同一 Index への矛盾した局所状態の割り当て
- 範囲外の Site 位置番号の使用
- Chain 内での Index の重複、および Site 数を別途指定した経路での入力数不一致
- 空間との接続時の Index の未配置・不足・不一致
- Site に所属しない Index の指定

### 7.4. 検証条件

Hermiticity と解析的なエネルギー期待値の検証には、実数の結合定数 `J` を使用する。

- 長さ `N` の open chain の辺数が、`N > 0` では `N - 1` となる。
- 通常の長さの periodic chain が末端と先頭の関係を持つ。
- `N = 0`, `N = 1`, `N = 2` の periodic chain が 7.2 節の規約に従う。
- nearest-neighbor 関係に self-loop や重複辺が存在しない。
- 向きのない nearest-neighbor 関係が site ordering に従って `(min(i,j), max(i,j))` に正規化され、関係の列挙結果が同じ ordering に基づく辞書順となる。
- Neel 積状態の norm が 1 である。
- 構築した Heisenberg Hamiltonian が Hermitian である。
- 代数的な演算子作用および内積から得た期待値が解析解と一致する。

配置について、Clone・Default のない Index の所有入力・借用列挙、Site 内・Site 間の重複拒否、発行・取得・複製での識別値の保持、範囲外・Site 数不一致を検証する。空間接続側では Factor・入れ子・空の空間との対応、未配置・過不足を検証する。二つの Index ペア列挙の順序・可変長・空も確認する。内部ラベルと Chain を跨ぐ所属チェックは対象外とする。

初期版の Chain では、Site と Site 内の Index 順序、空 Site、各 Site 共通の自由度数による発行経路を検証する。モデル構築側では利用側で保持する grouping、新しく構成する全空間の因子順序、および Site 順と異なる既存全空間への接続を検証する。

## 8. 代表ユースケースと受入条件

### 8.1. 縦断シナリオ

次の処理を一貫して実行できることを、代表的な縦断シナリオとする。

1. 長さ `L` の一次元 spin chain を構築する。
2. 各 site に spin-1/2 の局所自由度を配置し、全 Hilbert 空間を構築する。
3. nearest-neighbor 関係から Heisenberg Hamiltonian を構築する。
4. 各 site の局所状態を交互に割り当て、Neel 積状態を構築する。
5. Hamiltonian の状態への代数的な作用を通じて、行列を生成せずにエネルギー期待値を計算する。
6. 同じ状態と演算子を密および疎の数値表現へ変換する。
7. 小規模系において、代数計算、密表現、および疎表現から得られる結果が一致することを検証する。

等方的 Heisenberg Hamiltonian を

```math
H = -J \sum_{\langle i,j\rangle}
    \left(S_i^x S_j^x + S_i^y S_j^y + S_i^z S_j^z\right)
```

とする。`L >= 1` の open chain の Neel 状態では、標準規約の下でエネルギー期待値が

```math
\langle \mathrm{Neel}|H|\mathrm{Neel}\rangle
= \frac{J}{4}(L-1)
```

となることを基準ケースとする。負符号の規約では `J > 0` を強磁性的結合とする。

0-site chain は辺を持たず、Hamiltonian とエネルギーは zero となる特例として検証する。

この基準ケースでは、結合定数 `J` は実数とする。代数オブジェクト自体は複素数係数を許容するが、複素数の `J` を与えた一般の場合に Hamiltonian が Hermitian であることは要件としない。

### 8.2. 受入条件

代表シナリオについて、以下を受入条件とする。

> 有限一次元 spin-1/2 chain について、定められた小規模系の規約を含む open または periodic な物理空間を構築できる。その nearest-neighbor 関係から、一般的な局所演算子積の有限和として Heisenberg Hamiltonian を構築できる。状態・演算子の加算と scalar multiplication、状態の tensor product、および演算子の積を行え、演算子の trace を行列化せずに計算できる。Neel 状態を積状態として構築し、完全な行列を生成せず、演算子の状態への代数的な作用を通じて期待値を評価できる。また、同じ状態と演算子を一貫した基底規約の下で密および疎の数値表現へ変換でき、代数計算を含む各経路の結果が指定した許容誤差内で一致することを検証できる。これらの処理は lazy な評価・基底展開、不要な copy の抑制、および差し替え可能な局所代数の抽象化という Non-functional Requirements を満たす。

始域・終域の保持、局所複合構造と基本因子の対応、基底・係数データなどについても、実装対象に対応する各章の検証条件を適用する。

初期版は、この代表シナリオに加えて、基本契約、基底展開・再展開と写像の表現行列、別の局所代数・非正規直交基底による抽象化、lazy 評価・共有、および不正入力を検証する。実行可能な利用例を含む完成条件は、[初期版の設計](design/initial-release.md#3-完成条件)に定める。

## 9. 初期版の制限と将来の機能候補

### 9.1. 初期版の提供範囲と制限

初期版は、spin-1/2 の 1D Chain を代数的に構築・評価し、密・疎の数値表現へ変換する一連の流れを提供する。局所構造の拡張、ordinary な Factor・入れ子 Tensor、状態・演算子の合意済みの演算と full/partial trace、二種類の演算子基底と tensor product 基底、通常の式木への展開・再展開、写像の表現行列、および単精度・倍精度の複素数を含む。

標準の状態 primitive は `up, down`、演算子 primitive は `I, Sx, Sy, Sz, S+, S-`、状態基底は `{up,down}`、演算子基底は `{I,Sx,Sy,Sz}` と `{I,S+,S-,Sz}` とする。幾何は open / periodic な 1D Chain と Site ごとの Index 配置を扱い、入れ子空間との接続は利用側が管理する。標準提供する局所構造は spin-1/2 のみとし、非公開の別の局所代数・非正規直交基底で共通機構の拡張性を検証する。

一つの系の全基本因子は同じ primitive 型 S・O とする。非公開の別の局所代数も独立した同種の系として検証し、spin と混在させない。

提供範囲と完成条件の詳細は [初期版の設計](design/initial-release.md)に定める。以下は初期版の対象外とする。

- 部分空間基底・射影、および制約付き部分空間
- 異種局所構造を一つの系に混在・合成する機能と、そのための型消去・保持機構
- 一つの空間内で、空・単因子 Tensor の同一視を適用した後にも通常と graded の tensor product が混在する構成
- 積和から和積への因数分解
- 特定の簡約ルールのみを選択して適用する独立した式変形操作
- source の自動保持、式の構造比較、および式表示 API
- Graded tensor product・fermion の実装。対応する数学的契約は保持する
- 保存・復元、評価結果のキャッシュ、並列評価・スレッド間共有
- Spin-1/2 以外の builtin algebra、1D Chain 以外の Geometry、ML・tensor network などへの追加接続

因子順序の変更と permutation はサポートしない。通常の trace を採用し、supertrace は現時点の対象外とする。

### 9.2. 未決・延期した機構と操作

分配だけ、局所積だけ、同類項の結合だけなど、特定の簡約ルールのみを選択して適用する操作は future work とする。初期版では局所規則による `evaluate` と、指定基底への展開・係数取得を提供する。基底展開や作用・内積・trace などの評価に必要な分配・局所積・係数処理は、この延期に含めない。

任意の式型を分解結果から組み立て直す汎用的な再構成機構は future work とする。ユーザ独自の式木への接続は公開契約に含めず、共通の線型構文の内部走査・構築方法は有限線型結合・式木・局所規則の返却形式と一体で設計する。共通式の評価結果の構築、局所式の配置、基底係数からの共通式の組立てはこの延期に含めない。

source の自動保持・式の構造比較・表示は後続へ延期する。入力の式を変更しない契約と、不変な部分構造の共有は維持する。

キャッシュ機構は未決の future work とし、初期版の必須機能・検証項目に含めない。導入するかどうか、対象・保持先・再利用条件・破棄・資源管理は今後検討する。初期版は必要な結果を要求時に計算する構成でよく、不変な式・空間・primitive の共有は引き続き採用する。

並列評価・スレッド間共有も未決の future work とし、初期版の必須機能・検証項目に含めない。初期版は単一スレッドで評価する構成でよく、スレッド間共有の条件と並列実行の方式は将来検討する。不変実体の共有と、3.1 節に定める Index の一意性の前提は維持する。

### 9.3. 追加の機能候補

以下を追加の機能候補とする。設計上の対応と個別リリースの実装範囲を区別する。

- spin-1/2 以外の builtin algebra の提供。spin-S および一般の qudit を含み、非公開の差し替え検証用 algebra とは区別する
- boson などの無限次元局所 Hilbert 空間、および局所 Hilbert 空間の truncation
- fermion、反交換関係、および符号規則
- symmetry sector、粒子数固定、および保存量
- density operator、mixed state、および状態ベクトルからの reduced density operator の構築
- 熱状態
- 自動対角化、固有値問題、および基底状態探索
- 時間発展
- 測定と確率 sampling
- 任意 graph、座標、距離、plaquette、および hyperedge
- parameterized operator、記号係数、および大規模な記号計算
- 一般的な式変形 system、高度な簡約戦略、および簡約結果の最適化
- 一般的な作用の等価性判定
- tensor network、MPS、および MPO への変換
- MPO の生成または最小化
- tensor network の truncation、gauge、および canonical form
- GPU、分散計算、および大規模計算向け backend

Fermion などについて本文書で定める合成・評価・検証規約は、対応する機能を実装する際に適用する。これらの規約があることと、個別リリースでその機能を実装することは区別する。
