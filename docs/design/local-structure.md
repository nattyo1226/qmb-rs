# 局所構造の設計

更新日: 2026-10-14

## 1. 対象と検討状況

本書は、局所構造の定義と一致条件に関する設計を記録する。[要件](../requirements.md)の局所構造に関する責任分離を前提とし、具体的な一致条件は後で議論する。

局所構造は、局所 Hilbert 空間と、その上で実現される代数・表現を定める。Index と選択基底は、局所構造とは区別する。

## 2. 未決事項

- 局所構造の一致を判定する具体的な契約

この契約では、比較対象とする代数・表現・パラメータ、および別々に構築した同じ定義の局所構造をどう扱うかを検討する。現時点では判定方式を決めない。

## 3. Index の契約との接続

[Index の契約](index.md)では、Index の一致と局所構造の一致を別に判定する。Index は局所構造や次元を持たず、自由度や Index を付与した局所状態・演算子が局所構造を保持する。Index と局所構造の対応を全体で登録・固定する機構は設けず、合成・埋め込み・評価に必要な整合性は操作の対象から検証する。

本書で今後定める一致条件は、その局所構造の照合に用いる。
